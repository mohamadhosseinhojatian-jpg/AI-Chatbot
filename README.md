# 🤖 AI Chatbot

A web-based AI chatbot built with Python, Flask, and Google Gemini API.

## 🚀 Features

- 💬 Real-time AI conversation
- 🌐 Web-based interface
- 🧠 Powered by Google Gemini
- 🇮🇷 Supports Persian and English
- 📱 Responsive chat interface

## 🛠️ Technologies

- Python
- Flask
- Google Gemini API
- HTML
- CSS
- JavaScript
